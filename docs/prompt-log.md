## 1. 작성 기준

이 표는 실제 대화와 업로드한 파일, 실행 화면을 바탕으로 정리했다. 요청 칸은 대화의 요약이며, 모든 문장이 내가 입력한 원문은 아니다. AI가 먼저 제안한 검토는 ‘AI 제안’으로 구분한다.

판단은 실제 파일 반영, 실행 확인 또는 명시적인 동의로 구분해 기록한다. 이유 칸은 AI와 함께 정리한 설계 근거이다. 사용성 개선 효과를 측정하거나 독립적인 사용자 조사를 실시한 것으로 기록하지 않는다.

## 4. 주요 수정과 적용 범위

### 평점 정보 수정
- 웹 텍스트에서 확인한 수치: 4.7
- 내가 제공한 캡처의 수치: 4.8 / 리뷰 25.5만개
- 과제 기록에서는 제공된 캡처의 수치를 사용한다.

### 기존 앱 분석의 범위 조정
- 오래된 불편 리뷰만으로 현재 IKEA에 필터나 3D 기능이 없다고 결론 내리지 않는다.
- 분류와 공간 적합성 판단에 관한 긍정 리뷰도 함께 사용한다.
- 리뷰를 설계 시사점으로 활용하며 자취생 전체의 수요를 입증한 자료로 사용하지 않는다.

### 추천 기능 설명
- 추천 모달은 미리 정한 후보를 보여 주는 UI 시연이다.
- 실제 AI 추론, 사용자 조건에 따른 필터링, 공간 적합성 자동 계산은 구현하지 않았다.
- 실행 코드에 없는 기능을 발표에서 완성된 기능으로 소개하지 않는다.

- 기존 촬영본의 대기 구간을 줄인 편집이며, 새 실행 장면을 생성하거나 서버 중지 장면을 추가한 것은 아니다.

### 기록에서 제외한 템플릿 예시
원본 prompt-log에는 provider 추가 후 제거, shared_preferences 저장 후 폐기 등의 설명용 예시가 있었다. 실제 수행한 이력으로 확인되지 않아 본 기록에서는 삭제했다.

### P08 — 미학적이고 미니멀한 디자인

| 칸 | 내용 |

| 적용 | A-2 `ListView + Card`, A-3 `GridView + Card`, `LayoutBuilder`. 600dp 미만은 목록, 이상은 그리드다. 목록과 상세의 이미지는 `BoxFit.contain`으로 전체 형태를 보여 준다. 코드 주석: A-2·A-3 P08. |

| 판단 | 카드 높이를 줄이려고 치수·가격을 생략하지 않는다. 학생은 카드가 조금 높아지더라도 핵심 정보를 유지하는 방안에 동의했다. 영상만으로 모든 창 크기나 콘솔 오류 유무를 검증한 것은 아니다. |

### P09 — 오류 인식·진단·복구 지원

| 칸 | 내용 |
|---|---|

| 적용 | A-5 `ErrorView + FilledButton`, B-7 사용 안내의 오류·재시도 분기. `_retry()`에서 다시 GET 요청을 보낸다. 코드 주석: A-5 P09, B-7 P09. |

| 판단 | 잠깐 사라지는 안내만 사용하지 않고 오류 안내와 재시도 버튼을 유지한다. 학생이 이 방향에 동의했다. 서버가 중지된 상황에서는 서버를 먼저 복구해야 한다. |

3. 자취핏의 설계 방향
   자취핏은 작은 공간에 놓을 수납 상품을 살펴보는 상황에 집중한다. 목록에서 가격·치수를 확인하고, 상세 화면에서 용도를 확인한 뒤, 후보 상품을 살펴보는 세 화면으로 구성한다.
현재 구현 범위:
- 상품 목록과 상세 화면에서 모의 상품의 가격·치수·용도를 제공한다.
- 화면 폭에 따라 목록과 그리드 배치를 전환한다.
- 로딩·오류·빈 상태를 구분하고 조회 실패 시 재시도 기능을 제공한다.
- 추천 모달은 미리 정한 후보를 보여 주는 UI 시연이다. 실제 AI 분석이나 사용자 조건에 따른 필터링은 구현하지 않았다.
4. 해석 범위
   수집한 리뷰는 서로 다른 시점의 개인 경험이다. 오래된 불편이 현재도 지속된다고 단정하지 않는다. 긍정 리뷰에는 분류와 3D 기능에 대한 평가도 있으므로, IKEA에 해당 기능이 없다고 주장하지 않는다.
자취생을 주요 사용자로 정한 것은 프로젝트의 기획 가설이다. 이 리뷰만으로 자취생 전체의 수요나 자취핏의 효과가 검증된 것은 아니다. 후속 사용성 평가에서는 상품의 치수와 가격을 비교하는 과정이 이해하기 쉬운지 확인한다.
제출용 화면 자료에서는 리뷰 작성자의 이름과 프로필 사진을 가리고, 날짜·별점·리뷰 내용과 출처는 유지한다.

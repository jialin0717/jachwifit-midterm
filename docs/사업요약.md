# 자취핏 v2 사업 요약

## 1 목표

자취핏은 **좁은 자취방의 수납용품을 고르는 대학생이 가격·치수·용도를 같은 순서로 살펴볼 수 있도록 돕는 Flutter UI 프로토타입**이다. 구매 전 필요한 정보를 먼저 확인하고, 목록에서 상세 안내로 이어지는 흐름을 단순하게 만드는 것이 목표다. 이번 중간프로젝트에서는 실제 판매보다 정보 비교와 화면 전환에 집중한다. 선택 시간 단축이나 구매 실패 감소는 아직 측정한 성과가 아니다.

## 2 대상 사용자와 퍼소나

**대상 사용자 가설:** 좁은 자취방에서 공간과 예산을 함께 고려해 수납용품을 찾는 대학생.

**가상 퍼소나 김민수 · 22세 · 원룸 거주 대학생 — 설계 가정**

- **상황:** 책상 옆에 쌓인 물건을 정리하기 위해 모바일 화면으로 수납용품을 살펴본다.
- **목표:** 자신이 재어 둔 공간의 크기와 상품의 가로·깊이·높이를 대조하고, 예산 안에서 후보를 고른다.
- **불편:** 상품을 바꿔 볼 때마다 가격과 치수를 기억해서 비교하기 번거롭다.
- **가상 요구:** “얼마인지, 놓을 자리에 들어갈 크기인지 먼저 보고 싶어요.”

이 퍼소나는 설계 방향을 설명하기 위한 가상 인물이며, 실제 인터뷰나 사용자 조사 결과가 아니다.

## 3 해결할 문제

작은 공간의 수납용품을 고를 때는 가격뿐 아니라 치수와 용도를 함께 확인해야 한다. 자취핏은 이 정보를 일관된 위치와 순서로 제시해 사용자가 직접 후보를 비교하도록 돕는다.

참고 앱 IKEA의 R01은 조건에 맞는 상품 탐색의 불편을, R02는 구체적인 분류의 장점을 보여 준다. 이를 비교 정보의 우선순위를 정하는 시사점으로 활용했다. **IKEA에도 가격·치수·필터가 이미 있으므로**, 기능이 없다는 주장 대신 자취방 수납이라는 좁은 사용 상황에 맞게 정보를 단순하게 구성하는 데 집중한다. 과거의 개별 리뷰가 현재 앱의 결함이나 자취생 전체의 요구를 입증하지는 않는다. 근거는 [리뷰 분석](리뷰분석.md)의 R01·R02를 따른다.

## 4 v2의 핵심 가치

- **비교에 필요한 정보 우선:** 화면 A에서 가상 상품 4개의 이미지·가격·가로·깊이·높이·용도를 같은 순서로 제공한다. 좁은 화면은 목록, 가용 너비 600dp 이상은 격자로 표시한다.
- **필요한 설명으로 연결:** 화면 B에서 상품 정보와 사용 안내를 탭으로 구분한다. 화면 C는 고정 후보 3개와 이유를 보여 주는 추천 예시이며, 실제 AI 분석이나 개인화는 수행하지 않는다.
- **상태와 다음 행동 안내:** JSON GET 조회의 로딩·오류·빈 상태를 구분하고, 조회 실패 시 다시 시도 버튼을 제공한다.

구현 범위는 모의 상품 정보 조회와 UI 흐름이다. 검색·필터, 자동 공간 적합성 검증, 결제·영구 저장은 구현하지 않았다. 핵심 가치는 **사용자가 공간과 예산을 판단할 정보를 쉽게 찾아 읽도록 구성하는 것**이며, 효과 검증은 향후 사용자 평가 과제로 남긴다.

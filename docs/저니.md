# 자취핏 사용자 저니

## 1 목표와 범위

이 저니는 **좁은 자취방의 수납용품을 고르는 대학생이 가격·치수·용도를 확인하고 후보를 정하는 과정**을 정리한다. 비교 단계의 부담을 설계 가설로 삼고, 이를 자취핏 v2의 목록·상세·추천 예시 화면과 연결한다.

- **퍼소나:** 김민수, 22세, 원룸 거주 대학생. 실제 조사 참여자가 아닌 설계용 가상 인물이다.
- **상황:** 책상 옆에 쌓인 물건을 정리하려고 수납용품을 살펴본다.
- **사용자 목표:** 놓을 공간의 크기와 상품 치수를 대조하고, 예산과 용도에 맞는 후보를 고른다.
- **저니의 끝:** 구매 전 후보 선택. 결제·배송·실제 사용 경험은 포함하지 않는다.
- **근거의 범위:** IKEA 리뷰 R01–R03의 개인 경험과 참고 UI에서 얻은 시사점이다. 행동·생각·감정은 가상 시나리오이며 관찰·인터뷰 결과가 아니다.

**현행과 제안 구분:** 아래의 현행 여정은 참고 앱 IKEA를 이용하는 상황을 가정한 것이다. 마지막 행은 같은 단계에 대응하는 자취핏 v2의 구현 내용이다. IKEA에는 이미 가격·치수·필터가 있으므로 해당 정보나 기능이 없다고 전제하지 않는다. v1은 참고 앱을 뜻하며 자취핏의 이전 출시 버전이 아니다.

## 2 단계별 저니

생각 행은 가상 퍼소나의 판단을 요약한 것으로, 실제 사용자 발언을 인용한 것이 아니다.

| 항목 | 1 필요 인식 | 2 상품 탐색 | 3 가격과 치수 비교 | 4 사용 안내 확인 | 5 후보 선택 |
|---|---|---|---|---|---|
| **단계 목표** | 정리할 물건과 놓을 위치 정하기 | 용도에 맞는 상품 찾기 | 공간과 예산에 맞는지 판단하기 | 설치·사용 시 확인할 점 파악하기 | 더 검토할 후보 정하기 |
| **현행 행동 가정** | 책상 옆 공간을 재고 예산을 생각한다 | IKEA에서 수납용품을 검색하고 분류·필터를 살펴본다 | 여러 상품의 가격·치수를 자신이 잰 공간과 번갈아 대조한다 | 후보의 상세 설명에서 용도와 설치 관련 정보를 읽는다 | 조건을 다시 확인하고 검토할 상품을 정한다 |
| **생각 가정** | 어느 정도 크기의 수납용품이 필요할까 | 원하는 크기와 용도의 상품부터 보고 싶다 | 이전 상품보다 저렴한가, 깊이까지 맞는가 | 놓을 수 있어도 쓰거나 이동하기 불편하지 않을까 | 이 후보를 고른 이유를 설명할 수 있을까 |
| **불편과 판단 부담 가설** | 필요한 공간·예산이 아직 명확하지 않다 | 여러 조건을 동시에 고려하며 탐색해야 한다 | 화면을 오가며 가격·가로·깊이·높이를 기억해야 할 수 있다 | 외형만 보고 실제 사용에 적합하다고 오해할 수 있다 | 확인한 조건을 놓치거나 공간 적합성을 확신하기 어렵다 |
| **감정 가설** | 정리하고 싶은 기대 | 탐색 기대와 약간의 부담 | **혼란·부담이 가장 큼 — LOW POINT** | 정보를 읽으며 불안이 일부 줄어듦 | 후보를 정한 안도감과 남은 확인 필요 |
| **배치한 리뷰와 해석** | 직접 대응 리뷰 없음 | **R01:** 조건에 맞는 탐색의 불편. **R02:** 세부 분류가 탐색을 돕는다는 긍정 평가 | **R01:** 치수 조건 탐색의 중요성. **R03:** 3D 공간 판단에 대한 긍정 평가를 참고해 공간 확인의 중요성 연결 | **R03 간접 연결:** 놓을 위치를 판단하는 가치를 사용 전 공간 확인 관점으로 해석 | 직접 대응 리뷰 없음. 앞 단계의 조건을 재확인하는 설계 가정 |
| **자취핏 v2 대응** | 별도 입력 화면은 구현하지 않음. 사용자가 공간과 예산을 미리 확인한다 | **A-2·A-3:** 모의 상품 4개의 가격·치수·용도를 같은 순서로 표시. 검색·필터는 없음 | **A-2·B-3·B-4:** 목록과 상세의 가격·치수 및 표시용 조건 태그를 읽고 직접 비교. 자동 적합성 판정은 없음 | **B-2·B-7:** 상품 정보와 사용 안내를 탭으로 구분. 모의 안내, 빈 상태, 조회 오류와 재시도 제공 | **B-6 → C:** 고정 후보 3개와 이유를 참고한 뒤 닫고 직접 판단. 관심 상품 체험은 안내만 표시하며 저장·결제하지 않음 |

### 감정 흐름과 최저점

**기대 → 탐색 부담 → 비교의 혼란과 부담 최저점 → 일부 안도 → 후보 선택의 안도와 남은 불확실성**

감정 곡선은 정성적인 **설계 가설**이며 측정 점수가 아니다. 3단계를 최저점으로 정한 이유는 예산과 가로·깊이·높이라는 여러 조건을 함께 대조해야 하기 때문이다. R01은 조건 탐색의 어려움을 참고하게 하지만, 이 단계의 감정이 실제로 가장 낮다는 사실까지 입증하지는 않는다.

자취핏은 이 지점에 가격·치수·용도의 일관된 표시를 적용했다. 비교 시간이나 선택 오류가 줄었는지는 아직 측정하지 않았다.

## 3 확장 행

아래는 같은 다섯 단계에 대한 추가 분석이다. **AI 활용 기회는 향후 검토할 아이디어이며 현재 기능이 아니다.** 필요한 데이터는 판단에 필요한 정보 또는 향후 요구사항으로, 앱이 수집·저장하고 있다는 뜻이 아니다.

| 확장 항목 | 1 필요 인식 | 2 상품 탐색 | 3 가격과 치수 비교 | 4 사용 안내 확인 | 5 후보 선택 |
|---|---|---|---|---|---|
| **사용기기** | 스마트폰 메모·줄자 사용을 가정 | 스마트폰의 쇼핑 앱을 가정 | 스마트폰 화면과 직접 잰 치수 메모 | 스마트폰 상세 화면 | 스마트폰에서 후보 재확인 |
| **AI 활용 기회** | 정리할 물건·사용 목적을 질문해 조건 정리를 돕기 | 사용자가 입력한 조건을 이해해 후보 탐색 돕기 | 신뢰할 수 있는 치수·가격을 바탕으로 비교 이유 설명하기. 공간 판정은 수치 검증과 사용자 확인 필요 | 원문에 근거해 설치·사용 주의사항을 요약하고 출처 표시하기 | 후보별 장단점과 미확인 조건을 설명하기. 현재 C는 고정 예시일 뿐 개인화하지 않음 |
| **어긴 원칙** | **잠재 위험 P02:** 사용자의 실제 공간·용도와 정보 표현이 맞지 않는 경우 | **잠재 위험 P08:** 핵심 조건보다 다른 정보가 앞서 탐색을 방해하는 경우 | **잠재 위험 P06:** 비교 정보를 기억에 의존하게 하는 경우. **P02:** 치수 단위·방향을 이해하기 어려운 경우 | **잠재 위험 P05·P10:** 설치 공간 확인이나 사용 안내가 부족한 경우 | **잠재 위험 P01·P10:** 추천·저장 기능의 실제 범위를 알리지 않아 오해하게 하는 경우 |
| **필요한 데이터** | 정리할 물건, 놓을 위치, 사용자가 잰 공간의 가로·깊이·높이, 예산 | 상품명·용도·종류·가격·치수. 현재 A는 모의 상품 4개 사용 | 실제 서비스에는 정확한 상품 치수·가격과 사용자의 공간·예산 정보 필요. 현재 앱은 사용자 조건을 입력·수집하지 않음 | 설치·이동 여유 공간, 사용 방법과 주의사항. 현재 B의 안내는 모의 데이터이며 실제 제품 매뉴얼이 아님 | 후보의 가격·치수·용도와 아직 확인하지 못한 조건. 현재 후보 이력·관심 상품은 저장하지 않음 |

‘어긴 원칙’은 과제의 행 제목을 유지한 것으로, **해당 상황에서 발생할 수 있는 사용성 위험**을 뜻한다. 모든 단계에서 실제 위반을 관찰했다거나 IKEA가 해당 원칙을 보편적으로 위반한다는 판정이 아니다. P번호는 [디자인 가이드](디자인가이드.md)의 닐슨 원칙 번호를 따른다.

사용기기는 시나리오의 가정이다. 자취핏의 실제 확인 환경은 로컬 Chrome이며, 모바일 크기 화면으로 시연했다. 실기기 검증을 완료했다는 뜻은 아니다.

## 4 리뷰와 구현 범위의 연결

- **R01 — 2021-02-10 · 1점:** 모바일 배치와 치수·색상·종류 기준 탐색의 불편을 요약한 리뷰. 2·3단계에 배치했다.
- **R02 — 2022-10-25 · 5점:** 크기·기능·형태의 구체적인 분류에 대한 긍정 리뷰. 2단계에 배치하고, 필요한 조건을 눈에 보이게 제공한다는 시사점을 얻었다. 자취핏에 분류 필터를 구현했다는 뜻은 아니다.
- **R03 — 2024-04-23 · 5점:** 3D로 공간과 놓을 위치를 판단하는 기능에 대한 긍정 리뷰. 3단계와 4단계의 간접 근거로 사용했다. 자취핏에는 3D·AR·자동 공간 검증이 없다.
- **R04는 이 저니에 배치하지 않았다.** 결제 결과 안내에 관한 경험은 구매 전 후보 선택까지인 이번 여정의 범위 밖이다. 자취핏의 조회 오류·재시도에는 결과 안내가 중요하다는 간접 시사점만 적용하며, 결제 오류와 조회 오류를 같은 문제로 다루지 않는다.

리뷰는 서로 다른 시기의 개인 경험이며, 현재 IKEA의 결함이나 자취생 전체의 요구를 입증하지 않는다. 리뷰 출처·캡처는 `docs/리뷰분석.md`, 구현과 화면 근거는 `README.md`와 `docs/디자인가이드.md`, 설계 판단의 기록은 `docs/prompt-log.md`를 따른다.

## 5 이후 확인할 질문

향후 사용자 평가에서는 다음을 확인한다. 아래 항목은 수행 결과가 아닌 검증 계획이다.

1. 사용자가 목록에서 가격·가로·깊이·높이를 정확히 찾아 자신의 조건과 비교할 수 있는가?
2. 실제로 3단계에서 가장 큰 부담을 느끼는가? 그렇지 않다면 최저점과 설계 우선순위를 수정한다.
3. 사용 안내와 추천 예시를 본 뒤에도 모의 데이터·고정 예시·저장되지 않는 체험이라는 범위를 이해하는가?

현재 저니의 결론은 **가격·치수·용도를 같은 순서로 보여 주고 필요한 안내로 연결한다는 설계 방향**이다. 구매 성공, 공간 적합성 보장, 개인화 추천 성과를 주장하지 않는다.
